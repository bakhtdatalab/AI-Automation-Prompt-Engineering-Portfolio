# Python Word Counter
A simple Python application developed in Google Colab that analyzes text entered by the user and provides useful statistics.

## Project Overview
This application counts:
Total words
Total characters
Total sentences
The project helped me practice Python string manipulation and text-processing techniques.

## Features
Count words
Count characters
Count sentences
Simple command-line interface

## Technologies Used
Python 3
Google Colab

## Concepts Practiced
String Methods
Loops
Functions
User Input
Text Processing

## How to Run
Open the notebook in Google Colab.
Run all cells.
Enter a paragraph or sentence.
The application displays text statistics.

## Learning Outcomes
String manipulation
Text analysis
Python functions
Basic data processing

## Future Improvements
