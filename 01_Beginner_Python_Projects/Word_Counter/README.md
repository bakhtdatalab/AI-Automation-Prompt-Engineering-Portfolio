# Python Word Counter

## Overview

A Python text-analysis application created in Google Colab. The program counts words and analyzes text entered by the user.

## Features

- Counts total words
- Counts characters
- Analyzes user-entered text

## Technologies Used

- Python
- Google Colab

## Skills Practiced

- String manipulation
- User input
- Functions
- Text processing

## Future Improvements

- Add sentence counting
- Calculate reading time
- Find frequently used words
- Export results to a file
