Project 1: Prompt Fundamentals

 

This project, include examples showing how a weak prompt can be improved.

Example 1: Improving a vague prompt

## Basic prompt:

Explain artificial intelligence.

## Improved prompt:

Act as an AI instructor.

Explain artificial intelligence to a beginner with basic computer knowledge.

Use simple English and include:

1. A clear definition
2. Three real-world examples
3. The difference between AI, Machine Learning, and Deep Learning
4. A short summary

Keep the explanation under 500 words.

## What this demonstrates
- Role definition
- Clear task instructions
- Audience identification
- Output structure
- Length constraints

## Example 2: Structured output

# Basic prompt:

## Give me ideas for an AI project.

## Improved prompt:

## Act as an AI project mentor.

## Suggest five beginner-friendly AI projects that use Python.

For each project, provide:

- Project title
- Problem being solved
- Required tools
- Main steps
- Expected learning outcomes
- Difficulty level

Present the answer in a Markdown table.

This shows that you understand how to control the format and usefulness of AI output.
