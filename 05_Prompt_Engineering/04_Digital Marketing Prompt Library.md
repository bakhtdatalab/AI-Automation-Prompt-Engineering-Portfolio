## Prompt 1: Content calendar

Create a 7-day content calendar for a small business.

For each day, provide:

- Content topic
- Platform
- Content format
- Caption
- Call to action
- Suggested hashtags

[Describe the audience]

Business:

[Describe the business]

Tone:

[Professional, friendly, educational, or promotional]

## Prompt 2: SEO content brief

Act as an SEO content strategist.

Create an SEO content brief for the following topic:

[Enter topic]

Include:

- Primary keyword
- Related keywords
- Search intent
- Suggested title
- Meta description
- Recommended headings
- Frequently asked questions
- Content outline

Do not claim keyword search volume unless reliable data is provided.

## Prompt 3: Product description

Act as an e-commerce copywriter.

Write a clear and persuasive product description.

Product:

[Product name]

Features:

[List features]

Target customer:

[Describe the customer]

Requirements:

- Use simple and professional language.
- Explain customer benefits.
- Avoid unsupported claims.
- Include a short call to action.
