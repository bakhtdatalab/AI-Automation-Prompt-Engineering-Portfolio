## Common AI Automation Workflow

Most projects in this portfolio follow a structured workflow:

```text
User Input or Business Data
             ↓
Python Data Preparation
             ↓
Input Validation
             ↓
Structured AI Prompt
             ↓
OpenAI API
             ↓
AI-Generated Output
             ↓
Review and Refinement
```

For data-driven projects, Python performs the calculations and data preparation before the information is sent to the AI model.

```text
Python
↓
Calculations and Data Validation
↓
OpenAI API
↓
Interpretation and Professional Output
```

This approach improves:

* Accuracy
* Transparency
* Reproducibility
* Control over calculations
* Output consistency

Each project is designed around a real-world workflow, including:

## How to Run a Project

1. Open the project folder.
2. Read the project-specific `README.md`.
3. Open the Google Colab notebook.
4. Install the required Python libraries.
5. Add the OpenAI API key to Google Colab Secrets.
6. Enable **Notebook access** for the API key.
7. Run the notebook cells in order.
8. Enter the required information.
9. Review the AI-generated output.

### API Key Security

Use the following secret name in Google Colab:

```text
OPENAI_API_KEY
```

Do not:

* Hard-code the API key in a notebook.
* Upload the API key to GitHub.
* Share the API key publicly.
