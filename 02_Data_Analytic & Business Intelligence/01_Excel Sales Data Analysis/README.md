# Excel Sales Data Analysis

## Project Overview

This project focuses on retrieving, analyzing, and visualizing sales data using Microsoft Excel.

The project demonstrates how Excel functions and reporting tools can be used to connect data, identify important values, summarize business performance, and present results visually.

## Project Tasks

The following tasks were completed:

1. Used **XLOOKUP** to retrieve the following information based on matching product names:

   - Sales
   - Quantity
   - Discount
   - Profit

2. Applied **Conditional Formatting** to highlight sales values greater than `100.4`.

3. Created a **PivotTable** to summarize total sales by category.

4. Created a **Pie Chart** to visualize total sales by category.
