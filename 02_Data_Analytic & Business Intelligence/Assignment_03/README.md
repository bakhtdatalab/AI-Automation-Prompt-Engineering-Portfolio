# Power BI DAX Calculations and Measures

## Project Overview

This project focuses on using DAX in Microsoft Power BI to create calculated columns and business measures.

The calculations were used to categorize sales and discounts and to calculate important business performance indicators.

## Calculated Columns

### 1. Sales Category

A calculated column named `Sales Category` was created.

Sales values were classified as:

- **High** — Sales greater than 100
- **Low** — Sales less than or equal to 100

### 2. Discount Category

A calculated column named `Discount Category` was created.

Records were classified as:

- **No Discount** — Discount value equals zero
- **Discount Applied** — Discount value is greater than zero

## Calculated Measures

The following measures were created:

- **Total Sales** — Sum of sales values
- **Quantity Sold** — Sum of quantity values
- **Total Orders** — Count of Order IDs
- **Total Profit** — Calculated using an iterator function

## Validation

A Matrix visual was used to validate and review the calculated measures.
