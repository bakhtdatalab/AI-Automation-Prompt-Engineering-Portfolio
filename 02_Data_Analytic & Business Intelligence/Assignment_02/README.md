# Power Query Data Cleaning and Transformation

## Project Overview

This project focuses on cleaning and transforming raw business data using Power Query Editor.

The goal was to improve data quality and prepare the dataset for accurate reporting and analysis.

## Data Preparation Tasks

### 1. Remove Empty Rows

Completely empty rows were removed to prevent errors in calculations, reports, and visualizations.

### 2. Remove Duplicate Records

Duplicate transactions containing identical values were identified and removed to ensure that each transaction appeared only once.

### 3. Standardize Customer Names

Customer names were converted to **Proper Case** to create a consistent and professional format.
