## Project Learning Path

### 1. Excel Data Analysis

**Tools:** Microsoft Excel

This project focuses on retrieving and analyzing sales data using XLOOKUP, conditional formatting, PivotTables, and charts.

**Key skills:**

- XLOOKUP
- Data integration
- Conditional formatting
- PivotTables
- Pie charts
- Sales analysis

---

### 2. Power Query Data Cleaning

**Tools:** Power BI and Power Query Editor

This project focuses on preparing raw data for analysis by removing empty and duplicate records, standardizing text, combining date fields, and separating location information.

**Key skills:**

- Data cleaning
- Removing empty rows
- Removing duplicates
- Text transformation
- Merging columns
- Splitting columns
- Data preparation

---

### 3. DAX Calculations and Measures

**Tools:** Power BI and DAX

This project focuses on creating calculated columns and business measures to categorize sales, analyze discounts, and calculate key performance indicators.

**Key skills:**

- DAX calculated columns
- DAX measures
- Sales categorization
- Discount analysis
- Total sales calculation
- Quantity analysis
- Order counting
- Profit calculation
- Matrix-based validation

---

### 4. Power BI Executive Dashboard

**Tools:** Microsoft Power BI

This project focuses on developing an interactive executive dashboard to present business performance through KPI cards, sales trends, category analysis, geographic visualization, and interactive filters.

**Key skills:**

- KPI cards
- Line charts
- Clustered bar charts
- Map visualizations
- Date hierarchies
- Slicers
- Interactive dashboard design
- Executive reporting
