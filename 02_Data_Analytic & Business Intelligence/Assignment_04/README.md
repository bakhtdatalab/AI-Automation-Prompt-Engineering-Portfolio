# Power BI Executive Sales Dashboard

## Project Overview

This project focuses on creating an interactive executive dashboard in Microsoft Power BI.

The dashboard combines key performance indicators, sales trends, category analysis, geographic analysis, and interactive filters on one page.

## Dashboard Components

### 1. KPI Cards

The dashboard displays:

- Total Orders
- Total Quantity Sold
- Total Profit
- Total Sales

### 2. Monthly Sales Trend

A Line Chart was created to show monthly sales trends.

- X-axis: Order Date
- Y-axis: Sales

A date hierarchy was created to support time-based analysis.

### 3. Sales by Category

A Clustered Bar Chart was created to compare total sales across categories:

- Technology
- Furniture
- Office Supplies

The categories were sorted from highest sales to lowest sales.

### 4. Sales by State

A Map Visualization was created to display total sales by state.

Larger bubbles represent higher sales values.

### 5. Interactive Slicers

The dashboard includes slicers for:

- Segment
  - Consumer
  - Corporate
  - Home Office

- Region
