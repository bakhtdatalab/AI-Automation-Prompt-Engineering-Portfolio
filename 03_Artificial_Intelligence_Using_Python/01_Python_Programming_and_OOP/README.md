# Python Programming and Object-Oriented Programming

## Project Overview

This exercise demonstrates fundamental Python programming concepts through practical tasks involving conditional statements, dictionaries, and Object-Oriented Programming (OOP).

The objective was to apply core Python concepts to solve simple programming problems and develop a basic chat system using classes and objects.

## Exercise Tasks

### Task 1: Salary-Based Tax Calculation

A Python program was developed to calculate tax based on a user's annual salary.

The program uses:

- User input
- Variables
- Conditional statements
- Comparison operators
- Arithmetic operations

The tax calculation is based on salary ranges defined in the exercise.

### Task 2: Word-Length Dictionary

A Python program was created to generate a dictionary in which:

- Each word is used as a key.
- The length of each word is stored as its value.

This task demonstrates the use of:

- Lists
- Dictionaries
- Loops
- String operations

### Task 3: Simple Chat System Using OOP

A basic chat system was developed using Object-Oriented Programming.

The system includes the following classes:

- `User`
- `Message`
- `ChatRoom`

These classes represent the main components of a simple chat application.

The project demonstrates how classes and objects can be used to organize related data and behavior in a structured way.
