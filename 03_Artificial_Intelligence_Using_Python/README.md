# Artificial Intelligence Using Python

This section contains hands-on exercises completed as part of my **Artificial Intelligence Using Python** learning journey.

The exercises demonstrate the progression from foundational Python programming to data preparation, machine learning, and deep learning.

Each exercise is included in two formats:

- **Jupyter Notebook (`.ipynb`)** — Contains Python code, explanations, execution steps, and outputs.
- **PDF (`.pdf`)** — Contains the completed exercise documentation and screenshots of the code and results.

## Learning Journey

The exercises follow this progression:

**Python Programming → Data Preprocessing → Machine Learning → Deep Learning**
